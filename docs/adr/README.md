# Décisions d'architecture (ADR)

Chaque fichier décrit une décision structurante : contexte, décision, conséquences, références
vers le plan. Le gabarit est le même pour toutes : titre, statut, date, puis les sections
Contexte, Décision, Conséquences et Références.

Une décision qui change ne **modifie pas** une ADR acceptée : on en ajoute une nouvelle qui
remplace l'ancienne, et on passe l'ancienne en statut « remplacé par ADR-00N ». Cela garde
la trace de ce qui a été pensé, et quand.
